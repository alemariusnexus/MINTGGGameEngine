# MINTGGGameEngine

A simple C++ 2D game engine, mainly intended for microcontrollers like the ESP32.

## Documentation

The full documentation, including features, supported platforms, setup, and
tutorials,
[is currently hosted here](https://dlerch.de/MINTGGGameEngine/doc/html/index.html).
If the linked documentation is not up to date, it can be built by running `doxygen`
in the repository's root directory.
